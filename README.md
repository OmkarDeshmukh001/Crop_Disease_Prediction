# 🌿 Crop Disease Predictor

An AI-powered web application that detects potato leaf diseases using **EfficientNetB4** transfer learning. Upload a leaf image and instantly get a diagnosis — Early Blight, Late Blight, or Healthy — along with treatment recommendations.

---

## 📁 Project Structure

```
Crop_Disease_Predictor/
├── raw_data/                         # Original images from Kaggle (untouched)
│   ├── Potato___Early_blight/
│   ├── Potato___Late_blight/
│   └── Potato___healthy/
├── dataset/                          # Auto-generated by splitfolders
│   ├── train/                        # 80% of images
│   ├── val/                          # 10% of images
│   └── test/                         # 10% of images
├── tf-env/                           # Python virtual environment
├── training.ipynb                    # Model training notebook
├── app.py                            # Streamlit web application
├── requirements.txt                  # Python dependencies
└── plant_disease_model.keras         # Saved model (generated after training)
```

## 🧠 Model

| Property        | Value                        |
|-----------------|------------------------------|
| Architecture    | EfficientNetB4               |
| Pretrained on   | ImageNet                     |
| Input size      | 160 × 160 × 3                |
| Output classes  | 3 (Early Blight, Late Blight, Healthy) |
| Phase 1 epochs  | 6 (frozen base)              |
| Phase 2 epochs  | 10 (fine-tuned top layers)   |
| Optimizer       | Adam (lr=1e-3 → 1e-5)        |
| Loss            | Sparse Categorical Crossentropy |

---

## 🔍 How Prediction Works

1. Image is resized to **160×160**
2. Pixels kept as raw **[0–255]** float32
3. `EfficientNet preprocess_input` applied (NOT `/255` — EfficientNet does its own scaling)
4. Model outputs softmax probabilities for all 3 classes
5. Highest confidence class is shown with treatment info

## 🐛 Common Issues

| Problem | Fix |
|--------|-----|
| `Model not found` error in app | Run all cells in `training.ipynb` first |
| `No Python at ...Python310...` | tf-env was created with wrong Python — delete and recreate with Python311 |
| `ipykernel` missing | Run `python -m pip install ipykernel -U --force-reinstall` inside tf-env |
| Wrong predictions / all same class | Do NOT divide image by 255 — use `preprocess_input` only |
| Streamlit deprecation warning | Use `width=` instead of `use_column_width=` for `st.image()` |
